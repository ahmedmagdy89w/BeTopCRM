## Become a Contributor

1. Read the [Contributing section](README.md#contributing) and the project conventions in [AGENTS.md](AGENTS.md).
2. Open a pull request with tests for your change.
3. Once it is merged, add yourself to the list above in the same or a follow-up pull request, with your name, GitHub handle and a one-line summary of your contribution.

Contributions are not limited to code. Translations, documentation, design, bug reports and testing all count.

Security reports go through [SECURITY.md](SECURITY.md), not public issues.
