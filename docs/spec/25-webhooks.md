# 25 — Webhooks

Allow external systems to subscribe to CRM events via HTTP callbacks. Supports event-driven integrations without polling.

---

## Database

### `webhook_endpoints`

| Column | Type | Notes |
|---|---|---|
| `id` | `bigint unsigned` | PK |
| `url` | `string` | HTTPS callback URL |
| `secret` | `text` | Encrypted HMAC signing secret; generated by default or supplied by an administrator |
| `events` | `json` | Array of subscribed event names, e.g. `["opportunity.created","opportunity.stage_changed"]` |
| `is_active` | `boolean` | Default `true` |
| `description` | `string` | Nullable — human-readable label |
| `created_by` | `foreignId` | → `users` |
| `last_triggered_at` | `timestamp` | Nullable |
| `failure_count` | `integer` | Default `0` — consecutive failures |
| `created_at` | `timestamp` | |
| `updated_at` | `timestamp` | |

### `webhook_deliveries`

| Column | Type | Notes |
|---|---|---|
| `id` | `bigint unsigned` | PK |
| `webhook_endpoint_id` | `foreignId` | → `webhook_endpoints` |
| `event` | `string` | Event name that triggered this delivery |
| `payload` | `json` | Full JSON payload sent |
| `response_status` | `integer` | Nullable — HTTP status code |
| `response_body` | `text` | Nullable — response body (truncated to 1KB) |
| `status` | `string` | `pending`, `success`, `failed` |
| `attempts` | `integer` | Default `0`; cumulative attempts across automatic retries |
| `delivered_at` | `timestamp` | Nullable |
| `created_at` | `timestamp` | |

## Models

### WebhookEndpoint

```php
class WebhookEndpoint extends Model
{
    use HasFactory;

    protected $fillable = [
        'url', 'secret', 'events', 'is_active',
        'description', 'created_by',
    ];

    protected $casts = [
        'events'    => 'array',
        'is_active' => 'boolean',
    ];

    protected $hidden = ['secret'];

    // Relationships
    public function creator(): BelongsTo       // → User
    public function deliveries(): HasMany      // → WebhookDelivery

    // Scopes
    public function scopeActive(Builder $q)
    public function scopeSubscribedTo(Builder $q, string $event)
}
```

### WebhookDelivery

```php
class WebhookDelivery extends Model
{
    use HasFactory;

    protected $fillable = [
        'webhook_endpoint_id', 'event', 'payload',

        'attempts', 'delivered_at',
    ];

    protected $casts = [
        'payload'      => 'array',
        'delivered_at' => 'datetime',
    ];

    // Relationships
    public function endpoint(): BelongsTo  // → WebhookEndpoint
```

## Payload Format

```json
{
    "id": "dlv_abc123",
    "event": "lead.created",
    "timestamp": "2026-03-08T10:30:00Z",
    "data": {
        "id": 42,
        "first_name": "John",
        "last_name": "Doe",
        "email": "john@example.com",
        "status": "new"
    }
}
```

**Signature header:** `X-CRM-Signature: sha256=<HMAC-SHA256 of raw payload body using endpoint secret>`

Receivers verify: `hash_equals(hash_hmac('sha256', $rawBody, $secret), $signatureHeader)`.

## Service

### WebhookService

```php
class WebhookService
{
    public function list(): LengthAwarePaginator
    public function create(array $data): WebhookEndpoint  // generates secret if omitted
    public function update(WebhookEndpoint $endpoint, array $data): WebhookEndpoint
    public function delete(WebhookEndpoint $endpoint): void
    public function rotateSecret(WebhookEndpoint $endpoint): WebhookEndpoint
    public function deliveries(WebhookEndpoint $endpoint): LengthAwarePaginator
    public function redeliver(WebhookDelivery $delivery): void  // creates a new delivery record
}
```

### WebhookDispatcher

```php
class WebhookDispatcher
{
    public function dispatch(string $event, array $data): void
    {
        $endpoints = WebhookEndpoint::active()->subscribedTo($event)->get();

        foreach ($endpoints as $endpoint) {
            DispatchWebhookJob::dispatch($endpoint, $event, $data);
        }
    }
}
```

Called from service layer methods (e.g., `LeadService::create()` calls `$this->webhookDispatcher->dispatch('lead.created', $lead->toArray())`).

## Job

### DispatchWebhookJob

```php
class DispatchWebhookJob implements ShouldQueue
{
    public $tries = 3;
    public $backoff = [10, 60, 300]; // 10s, 1m, 5m

    public function handle(): void
    {
        // Update the same delivery row for each attempt
        // Send HTTPS POST with JSON payload + signature header; do not follow redirects
        // Retry unsuccessful HTTP responses and transport errors using queue backoff
        // On success: status = 'success', reset failure_count
        // After the final failure: status = 'failed', increment failure_count once
        // If failure_count >= 10: auto-disable endpoint (is_active = false)
    }
}
```

**Timeout:** 30 seconds per request.

## Validation

### StoreWebhookEndpointRequest

```php
'url'         => 'required|url|starts_with:https',
'events'      => 'required|array|min:1',
'events.*'    => 'string|in:lead.created,lead.updated,...', // all supported events
'secret'      => 'nullable|string|min:32|max:255',
'description' => 'nullable|string|max:255',
'is_active'   => 'boolean',
```

Webhook URLs must resolve exclusively to public IP addresses when saved and immediately before delivery. Redirects are disabled to prevent access to internal services. Secrets are encrypted at rest; generated secrets are returned only once after creation or rotation.

### UpdateWebhookEndpointRequest

Same as store, all fields optional.

## Controller

### WebhookEndpointController

```php
class WebhookEndpointController extends Controller
{
    public function index()                     // GET /webhooks
    public function store(StoreWebhookEndpointRequest $r)  // POST /webhooks
    public function show(WebhookEndpoint $webhook)         // GET /webhooks/{webhook}
    public function update(UpdateWebhookEndpointRequest $r, WebhookEndpoint $webhook)  // PUT
    public function destroy(WebhookEndpoint $webhook)      // DELETE
    public function rotateSecret(WebhookEndpoint $webhook) // POST /webhooks/{webhook}/rotate-secret
    public function deliveries(WebhookEndpoint $webhook)   // GET /webhooks/{webhook}/deliveries
    public function redeliver(WebhookDelivery $delivery)   // POST /webhook-deliveries/{delivery}/redeliver
}
```

## Endpoints

| Method | URI | Action | Description |
|---|---|---|---|
| `GET` | `/webhooks` | `index` | List webhook endpoints |
| `POST` | `/webhooks` | `store` | Create endpoint (returns secret) |
| `GET` | `/webhooks/{webhook}` | `show` | Show endpoint details |
| `PUT` | `/webhooks/{webhook}` | `update` | Update endpoint |
| `DELETE` | `/webhooks/{webhook}` | `destroy` | Delete endpoint |
| `POST` | `/webhooks/{webhook}/rotate-secret` | `rotateSecret` | Generate new secret |
| `GET` | `/webhooks/{webhook}/deliveries` | `deliveries` | List delivery attempts |
| `POST` | `/webhook-deliveries/{delivery}/redeliver` | `redeliver` | Retry a delivery |

## Scheduled Cleanup

Add to `PruneAuditLogs` command (or separate command):

```php
// Prune webhook deliveries older than 30 days
WebhookDelivery::where('created_at', '<', now()->subDays(30))->delete();
```
